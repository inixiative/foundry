## Corrections

Thread selection previously combined the new thread ID with old messages in a
reactive persistence effect. Writes now use the originating ID at each mutation,
and selection updates are batched. Completed stream updates persist explicitly.
Late history responses cannot overwrite newly appended messages. Old traces no
longer mask layer selection. Inspecting contents no longer touches cache access
times. Injection badges now use pre-work snapshots instead of post-work hashes.

## Remaining Gates

Production ThreadFactory still shares mutable stacks and agents; the fixture
does not prove production isolation. Main-thread-only middleware and subscribers
also prevent equivalent lifecycle behavior on new threads. The inspector labels
shared ownership; per-domain three-part state still needs explicit fields rather
than legacy name heuristics. Layer mutation buttons were withheld because they
targeted main's stack.

Durable thread/cache/trace recovery, failed-turn evidence, native input wrapping
and tool-followup capture, child sessions, and Oracle evaluation remain incomplete.
Startup auto-naming overwrote the restored title; it was restored through the API.
Preserving names across restart is another acceptance case.

Astra live execution, native capability parity, mobile layout, database tests,
and direct-versus-Foundry latency baselines were not tested in this pass.
